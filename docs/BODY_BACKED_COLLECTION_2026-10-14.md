# 제목에서 놓친 장비 기사의 본문 기반 수집 보완

## 원인과 대상

[KBS 원문](https://n.news.naver.com/mnews/article/056/0012273846?sid=100)은 육군의 TMMR 도입 장비가 차량 연결선 문제로 운용되지 못한 보도다. 기존 실행38577716298에서 검색 응답에 들어왔으나 `candidate_parse decision=irrelevant`로 본문 확인 전에 탈락했다. 발행 시각은2026-10-14 21:34 KST였다. API 장애나 미발행으로 설명할 수 없다.

앞선 최종 선정20건의 검토만으로는 초기 검색 파싱에서 사라진 기사를 검증할 수 없었다. 이번 회귀 검증은 검색 응답 파싱부터 본문 추출·날짜 검증·카테고리 선정·CLI 출력까지 대상으로 한다.

## 동작 변경

1. 무전기·드론·레이더 등 장비명이 있으나 제목만으로 관련성을 판단하지 못하면, 기존 후보 풀에 `requires_body_review=True`로 보존한다. Google RSS의 정부 분류 경로에서도 본문 확인 전에 잘못 폐기하지 않는다.
2. 기존 본문 다운로드를 재사용한다. 군·장비·도입/납품/운용/시험 등의 활동이 주요 문단에서 함께 확인돼야 관련성을 확정한다. 단순히 장비 단어 하나가 있다는 이유로 발행하지 않는다.
3. 본문에서 도입·납품과 결함·방치·운용 불가 등의 문제가 확인되면 ‘방위사업 관련 동향’으로 배정한다. 제목에 ‘육군’이 있든 없든 같은 사건은 같은 본문 기준으로 분류한다.
4. 관련성이 확인되면 보류 후보로만 남기지 않고 `accepted`, `requires_body_review=False`로 바꿔 최종 선정 대상으로 사용한다. 기존 최신순·중복·수량 규칙은 그대로 적용한다.
5. 새 본문 확인 후보가 본문을 확보하지 못하거나 근거가 부족하면 미확인 상태로 선정에서 보류한다. 기존 정상 기사의 일반적인 카테고리 불확실·본문 부재 처리까지 일괄 제외로 바꾸지 않는다.
6. 블로그·댓글·게임·주식 실적·명시적 외국 무관 주제 등 기존 제외 조건을 우회하지 못하게 한다. 허구·오피니언·차단 매체·원문 날짜 검증 경로도 유지한다.
7. TMMR 및 전술 다대역 다기능 무전기를 검색어에 추가한다. TICN·전술정보통신체계 검색은 기존대로 유지한다.

카테고리별 최대5건/최소3건 설정과 예약·발송 워크플로는 변경하지 않았다. 특정 제목·URL·매체를 예외 승인하는 생산 코드는 추가하지 않았다. 주요 문단의 관련성 근거 범위는1600자이며, 기존 본문 추출 상한4000자는 그대로다. 본문 끝의 부수적 군 관련 언급만으로 민간 기사를 승격하지 않기 위한 제한이다.

## 실제 원문 확인

운영 `extract_main_text`로 사용자 제공 Naver URL의 원문1121자를 추출했고 TMMR이 포함됐음을 확인했다. 제목·발행 시각을 이용한 검색 응답 재현 입력을 실제 파서에 제공한 결과:

- 검색 파싱: 1건 보존, 본문 확인 필요 표시.
- 본문 판정: `accepted / policy`.
- 최종 `build_briefing`: 원래 제목·URL을 유지한 채 ‘방위사업 관련 동향’에 포함.

로컬에는 API 인증정보가 없으므로 이 원문 검증의 검색 응답은 재구성한 입력이다. 실제 네이버 응답에 해당 기사가 있었던 사실은 기존 GitHub 실행 로그에서 별도로 확인했다.

## 회귀 검증 범위

- 정상 육군 무전기 본문은 최종 정책 카테고리에 포함.
- 제목에 육군이 명시된 변형도 같은 분류.
- 장비 표현을 드론·레이더로 바꿔도 본문 근거로 판정.
- 민간 작업용·등산용 무전기, 본문 미확인 및 민간 본문 끝의 군 관련 배경은 선정하지 않음.
- 블로그·댓글·게임·주식 실적·튀르키예 훈련기·우크라이나 자국산 미사일의 기존 제외 유지.
- 실제 원문 추출과 원문 발행일 검증을 거친 CLI `--dry-run` 출력 확인. 네트워크 응답과 시계만 고정하고 선정 함수를 모의하지 않음.
- 한국 시간2026-10-15 06:30에서도 해당 기사 날짜가 유효하며 CLI 미리보기에 포함되는지 확인.
- 로컬 dry-run에서 Copilot·Telegram 호출이 없음을 검사.

다음 날 모든 신규 기사·매체 접근·선정 경쟁까지 미리 보증하는 것은 아니다. 충분한 관련 기사가 있으면 기존 수량 내에서 최신성·중복 기준에 따라 선정한다. 예약 발송이 체크아웃하는 main 코드에 이 수정이 반영되면 동일한 제목 누락 경로에 적용된다.

최종 로컬 검증: 전체536개 테스트·52개 하위 테스트 통과, Ruff 통과, BasedPyright 0 errors/0 warnings/0 notes, `git diff --check` 통과. 변경 Python 파일은 빈 줄·주석을 제외하고 각각200줄 미만이며, 불변 기사 모델에 본문 검증 필요 여부만 추가했다.
