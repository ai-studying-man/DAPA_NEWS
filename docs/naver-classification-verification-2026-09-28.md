# 네이버 기반 분류·중복 제거 보완 검증

2026-09-28, 로컬 작업 내용. 아직 커밋·푸시하지 않았으며 GitHub 예약 실행에는 반영 전이다.

## 변경 내용

- 제목에서 확인되는 주제를 우선 판정한다. 네이버 설명문의 배경 정책·수출 언급이 이미 판정된 제목의 주제를 덮어쓰지 않는다.
- 제목에 수집 범위를 뒷받침하는 근거가 없는 기사는 설명문에 방사청·방산이 등장해도 제외한다. 근거 없는 분류를 방위사업 카테고리로 자동 배정하지 않는다.
- 기술교범·국제표준은 방위사업, 기업의 방산 진출·해외 현지생산·해외 인도는 수출/기업동향, 구체적인 무기 무인화는 무기체계로 분류한다.
- 게임, 취업, 주가 움직임, 기관 유치 경쟁 등의 비대상 제목을 보완한다. 외국 군 조달은 제목에 한국산 대상 또는 한국 공급자 근거가 필요하다.
- 카테고리별 정원을 적용하기 전에 전체 후보에서 중복 대표 기사를 선정한다. 기존 최신성·조회수·검색 순위 기준은 유지한다.
- 국가, 계약/인도 단계, 성공/취소가 다르면 공통 설명문·본문만으로 합치지 않는다. 서로 다른 날짜의 반복 행사를 무기한 같은 사건으로 취급하지 않는다.
- 장병이음/장병e음 별칭, 육군·대전 AX 협력 발표, FEMIA 협력 등의 확인된 사건 표현을 보완했다. 회사와 국가가 같다는 이유만으로 협력 기사를 합치지 않도록 상대 기관 근거를 요구한다.
- ‘인도네시아’라는 국가명을 무기 ‘인도’ 동작으로 오인하지 않는다.

## 유지한 운영 체계

4개 카테고리와 카테고리별 최대 5건, 3건 미만일 때의 기존 2일 보충 기준을 유지했다. 검색어, API HUB 인증/속도 제한, Google 병행 설정, GitHub Actions/CRON, Telegram 발송 경로는 변경하지 않았다. 부족한 건수를 무관한 기사로 채우지 않는다.

새 Python 파일은 기존 실행 경로가 가져다 쓰는 내부 모듈이다. 독립 실행 프로그램이나 새로운 스케줄러가 아니다. RSS 파싱, 분류, 제목 규칙, 중복 비교, 토큰 정규화를 분리하고 기존 공개 호출 경로를 유지했다.
